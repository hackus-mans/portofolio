# Hackus Mans — Cybersecurity Portfolio

Portfolio de **NAKORE Yendoubouame Joseph (Hackus Mans)**.

## Base du projet

Cette version est une adaptation profonde du template open-source **RyanFitzgerald/devportfolio**, distribué sous licence MIT.

La base apporte l’architecture Astro/Tailwind et une organisation par composants. La direction artistique, les sections et le contenu ont été refondus pour un portfolio cybersécurité.

## Stack

- Astro
- Tailwind CSS
- GitHub Actions
- GitHub Pages

## Sections

- Profil et méthodologie
- Compétences techniques
- Projets : HoneyShield, CyberMind X, Knowledge Base
- Pratique offensive + défensive
- Badges et certifications
- CPTS / CAPT en préparation
- Formation
- Labs et write-ups

## Développement

```bash
npm ci
npm run dev
```

Build de production :

```bash
npm run build
npm run preview
```

## Déploiement

Astro est configuré pour :

```text
https://hackus-mans.github.io/portofolio/
```

Le workflow GitHub Pages se trouve dans `.github/workflows/deploy-astro.yml`.

## Sécurité éditoriale

Les contenus offensifs publiés doivent provenir d’environnements autorisés : CTF, labs, machines personnelles ou plateformes d’entraînement. Ne jamais publier de secrets, tokens, mots de passe réels, données privées ou cibles non autorisées.
