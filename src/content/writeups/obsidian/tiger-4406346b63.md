## Résultats et enseignements



> **Info —** Mini-cours — VNC
> **VNC (Virtual Network Computing)** permet de voir et contrôler à distance une interface graphique.
>
> Il repose généralement sur le protocole **RFB (Remote Framebuffer)** :
>
> ```text
> Machine distante
>      │
>      │ affichage / framebuffer
>      ▼
> Serveur VNC
>      │
>      │ RFB
>      ▼
> Client VNC
>      │
>      ▼
> Mon écran
> ```
>
> Le serveur envoie les changements d'affichage vers le client, tandis que le client renvoie les événements clavier et souris.
>
> Les ports VNC suivent souvent la convention :
>
> ```text
> Port = 5900 + numéro du display
> ```
>
> Exemples :
>
> | Display | Port |
> |---|---:|
> | `:0` | `5900/tcp` |
> | `:1` | `5901/tcp` |
> | `:2` | `5902/tcp` |
>
> Un **display** comme `:1` représente une instance graphique, pas forcément un écran physique.
>
> Deux modèles sont fréquents :
>
> - **Session partagée** : VNC expose une session graphique déjà existante.
> - **Session virtuelle** : le serveur VNC crée son propre environnement graphique, par exemple `Xtigervnc :1`.
>
> En pentest, trouver VNC signifie surtout : identifier le protocole, le type d'authentification, le programme VNC, le display exposé et l'utilisateur de la session.

## Reconnaissance

La cible répond au réseau :

```bash
ping 172.20.4.31
```

Un scan de services permet ensuite d’identifier le service exposé :

```bash
nmap -PN --disable-arp-ping -n --min-rate 5000 -sV 172.20.4.31
```

Résultat :

```text
PORT     STATE SERVICE VERSION
5901/tcp open  vnc     VNC (protocol 3.8)
```

Le port `5901/tcp` expose donc un service **VNC** utilisant le protocole **RFB 3.8**.

Pour confirmer directement la bannière du service :

```bash
nc 172.20.4.31 5901
```

Résultat :

```text
RFB 003.008
```

`RFB 003.008` correspond à **RFB 3.8**, le protocole utilisé par VNC.

## Énumération du service VNC

Un second scan avec les scripts Nmap par défaut permet d’obtenir des informations supplémentaires sur la sécurité du service :

```bash
nmap -PN --disable-arp-ping -n --min-rate 5000 -sV -sC 172.20.4.31
```

Résultat :

```text
5901/tcp open  vnc     VNC (protocol 3.8)
| vnc-info:
|   Protocol version: 3.8
|   Security types:
|     None (1)
|_  WARNING: Server does not require authentication
```

Le serveur annonce :

```text
Security types: None
```

Il n’exige donc **aucune authentification VNC**.

## Connexion au bureau distant

Le port `5901` correspond généralement au display VNC `:1` :

```text
5900 + 1 = 5901
```

Connexion :

```bash
vncviewer 172.20.4.31:1
```

Résultat :

```text
Connected to RFB server, using protocol version 3.8
No authentication needed
Authentication successful
Desktop name "debian:1 (leo)"
```

L’accès au bureau distant est obtenu sans mot de passe.

## Énumération locale

### Utilisateur de la session

Depuis le terminal de la session VNC :

```bash
whoami
```

Résultat :

```text
leo
```

L’utilisateur associé à la session VNC est donc **`leo`**.

### Système

```bash
cat /etc/os-release
```

Résultat principal :

```text
PRETTY_NAME="Debian GNU/Linux 11 (bullseye)"
```

La machine fonctionne sous **Debian GNU/Linux 11 (bullseye)**.

### Programme VNC en cours d’exécution

Pour identifier le serveur VNC :

```bash
ps aux | grep "vnc"
```

Ligne importante :

```text
/usr/bin/Xtigervnc :1 -rfbport 5901 -localhost=0 -SecurityTypes None ...
```

Le programme VNC réellement utilisé est :

```text
Xtigervnc
```

Cette ligne confirme également plusieurs éléments découverts depuis le réseau :

```text
Display        :1
Port RFB       5901
SecurityTypes  None
```

## Analyse des connexions VNC précédentes

Le répertoire VNC de l’utilisateur contient plusieurs fichiers :

```bash
cd ~/.vnc
ls -la
```

Un fichier particulièrement intéressant apparaît :

```text
connections.log.backup
```

Pour rechercher la connexion datant du **23 février 2023** :

```bash
cat connections.log.backup | grep "23"
```

Résultat :

```text
Thu Feb 23 08:35:42 2023
Connections: accepted: 10.1.9.23::42391
```

L’adresse IP du client ayant établi la connexion VNC est :

```text
10.1.9.23
```

Le nombre `42391` correspond au **port source temporaire** utilisé par le client lors de cette connexion.

## À retenir

- VNC utilise le protocole **RFB** pour transporter l’affichage distant et les interactions clavier/souris.
- Le port `5901` est généralement associé au display `:1`.
- `SecurityTypes None` indique ici qu’aucune authentification VNC n’est requise.
- `Xtigervnc :1 -rfbport 5901` relie directement le **display `:1`** au **port TCP 5901**.
- Les fichiers présents dans `~/.vnc/` peuvent contenir des informations utiles sur la configuration et l’historique des connexions.
