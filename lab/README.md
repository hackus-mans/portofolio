# Linux Lab

Welcome to the portfolio's GitHub Codespaces lab.

This workspace is intentionally simple: it gives you a real Linux terminal with common development and networking tools so you can explore the command line without installing anything locally.

## Start

```bash
./check-environment.sh
```

Then use the folders:

```text
lab/
├── exercises/   # guided exercises will live here
├── playground/  # free experimentation
└── notes/       # your own notes
```

## Available tools

Examples include:

- Bash
- Python 3
- GCC / G++
- Git
- curl / wget
- jq
- OpenSSL
- Nmap
- iproute2 / net-tools
- DNS utilities
- traceroute
- tcpdump
- Vim / Nano
- ripgrep
- tmux
- shellcheck

## Persistence

This is a GitHub Codespace, not a disposable browser shell. Closing the browser does **not** immediately delete it. GitHub can stop it after inactivity, and you can later resume or delete it from your Codespaces page.

## Responsible use

Use the environment for learning, development, your own systems, CTFs and explicitly authorized labs.
